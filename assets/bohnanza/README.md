# ボーナンザ カード画像

ここにスキャンしたカード画像（PNG）を置くと、アプリが**自動でプレースホルダー表示から画像表示に切り替わります**。特別な登録作業は不要です。ファイルを置いて、ブラウザをリロードするだけです。

**2026-09-05 時点で 8しゅるいの豆ぜんぶ そろっています**（`back.png` だけ まだ）。

## 置くファイル名

| ファイル名 | 豆の名前 |
|---|---|
| `blue.png` | あおまめ |
| `chili.png` | チリまめ |
| `stink.png` | そらまめ |
| `green.png` | みどりまめ |
| `soy.png` | だいず |
| `blackeye.png` | くろめまめ |
| `red.png` | あかまめ |
| `garden.png` | にわまめ |
| `back.png`（任意） | カード裏面 |

## 注意点

- 形式は **PNG**、**縦長のカード画像**を想定しています。表示は 230x366 くらいなので、それ以上に大きくしても意味がありません。
- **かならず減色して軽くしてから置いてください**（1まい 30〜45KB めやす）。
- 上記の名前でファイルを置いてリロードするだけで、その豆から自動的に画像表示へ切り替わります（一部の豆だけ画像を用意する、という置き方も可能です）。
- 画像が無い豆は、豆色の枠＋絵文字＋名前＋豆メーターのプレースホルダーで代わりに表示されるので、画像が揃うまでの間もゲームは問題なく遊べます。
- **ファイル名を変更する場合は `bbg.js` 側の `BOHNANZA_BEAN_DEFS` の修正が必要です**（このフォルダに置くだけでは対応できません）。ファイル名は上記の一覧のとおりにしてください。
